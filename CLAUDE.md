# Polski Kurwa — тренажёр польского языка

Учебный проект: интерактивные тесты по польскому для самостоятельного изучения (A1 → выше).
Интерфейс и объяснения — **на русском**, материал — на польском.

> Этот файл — рабочая память проекта. Читай его перед каждой задачей и **обновляй**,
> когда меняется структура, добавляется модуль или принимается новое решение.

---

## 1. Файлы

Репозиторий = сайт на GitHub Pages. Всё, что лежит в корне, публикуется как есть.

| Файл | Что это |
|---|---|
| `index.html` | Сам тренажёр: спряжение глаголов в настоящем времени, A1. Автономный — один HTML со встроенными CSS и JS, без сборки и без зависимостей. Точка входа сайта. |
| `manifest.webmanifest` | PWA-манифест: имя, иконки, `display: standalone`, цвета. |
| `sw.js` | Service worker. Стратегия **сеть первым делом, кэш как запасной вариант** — онлайн всегда свежая версия, офлайн последняя загруженная. Версию бампать не надо. |
| `icons/` | `icon.svg` — исходник (серифная «ę» на терракоте), `icon-180/192/512.png` и `icon-maskable-512.png` генерятся из него через `sips`. |
| `deploy.sh` | Публикация одной командой. |
| `.nojekyll` | Отключает Jekyll на GitHub Pages. |
| `CLAUDE.md` | Этот файл. |

**Версионирование — через git**, не через имена файлов. Раньше было
`index.html`; теперь это `index.html`, а история живёт в коммитах.

Когда тренажёров станет больше одного: текущий переезжает в `czasowniki.html`,
а `index.html` становится списком модулей. Иконка на телефоне ведёт на `/`,
так что она автоматически станет этим списком — переустанавливать ничего не нужно.

## 2. Архитектура одного файла

Порядок внутри HTML (строки указаны для v6_2, они сдвигаются при правках):

```
<head> мета + PWA-теги             1–16     manifest, apple-touch-icon, viewport-fit
<style> :root { --цвета }          17–25    палитра (бумажно-бежевая тема)
<style> остальное                  26–374   все стили
<body> header / #app / footer      376–387  «скелет»: весь UI рисуется в #app из JS
.modal-backdrop / #modalBox        389–391  общий модал (таблица спряжения + подтверждения)
<script>                           393+
  PERSON_LABEL / PERSON_ORDER      394–402  6 лиц
  PARADIGMS                        404–434  29 глаголов × 6 форм
  EXCEPTIONS                       436      Set неправильных глаголов
  CONJ_GROUPS                      438–487  группы спряжения A–E
  DATA                             489–640  122 вопроса
  движок                           642+     shuffle → batches → 3 экрана
  регистрация service worker       конец
```
(строки поплывут при правках — ориентируйся на имена констант)

### Модель данных

```js
PARADIGMS["mówić"] = ["mówię","mówisz","mówi","mówimy","mówicie","mówią"]
// строго в порядке PERSON_ORDER: ja, ty, on/ona/ono, my, wy, oni/one

CONJ_GROUPS.A = {
  label:      "I спряжение (тип czytać, -am/-asz)",  // полное, в фидбэке ошибки
  shortLabel: "I спряжение",                          // короткое, в модале и итогах
  infEnding:  "-ać",                                  // окончание инфинитива
  baseVerb:   "czytać",                               // образец группы
  verbs:      [...],                                  // членство определяется ЗДЕСЬ
  endings:    { ja:"-am", ty:"-asz", ... }            // ключи = PERSON_ORDER
}

DATA[i] = {
  v:        "mówić",              // ключ в PARADIGMS (обязателен!)
  person:   "on/ona/ono",         // одно из PERSON_ORDER
  sentence: "Ona ___ po niemiecku.", // ровно один плейсхолдер ___
  answer:   "mówi"                // = PARADIGMS[v][индекс person]
}
```

### Группы спряжения (текущая раскладка)

| Ключ | Ярлык | Инфинитив | Образец | Глаголы |
|---|---|---|---|---|
| A | I спряжение | -ać | czytać | czytać, mieszkać, słuchać, znać, grać, pomagać, pływać |
| B | на -ować | -ować | pracować | pracować, kupować, gotować |
| C | II спряжение | -ać / -ić | pisać | pisać, pić |
| D | III спряжение | -ić / -yć | mówić | mówić, robić, lubić, widzieć, tańczyć, uczyć się, jeździć, spać |
| E | тип на -mieć | -mieć | rozumieć | rozumieć |
| — | Исключения (`EXCEPTIONS`) | — | być | być, mieć, iść, jechać, jeść, chcieć, móc, wiedzieć |

### Движок

- `BATCH_SIZE = 10`, `MAX_TESTS = Math.floor(DATA.length / BATCH_SIZE)` — растёт сам при добавлении вопросов.
- `buildBatches()` — один `shuffle` всего `DATA`, режется на десятки. **Внутри сессии вопросы не повторяются.**
- Три экрана через `state` + `render()`: `start` (степпер + чипы 1/3/5/Все) → `quiz` → `summary`.
- `normalize()` = trim + lowercase + схлопывание пробелов. **Диакритика сравнивается строго**: `mowie` ≠ `mówię`.
- Проверка: `checkAnswers()` красит карточку, пишет фидбэк, копит `stats` (по группам + исключения).
- Фидбэк ошибки содержит кликабельную ссылку `.conj-link[data-verb]` → модал с полной таблицей форм.
- Итоги: SVG-радиал с анимацией, столбики ошибок по группам, до 2 советов «что подтянуть».
- Enter в поле = переход к следующему; в последнем = «Проверить». Пустые поля → модал-подтверждение.

## 3. Правила при изменениях

1. **Ноль зависимостей и ноль сборки.** Никаких CDN и npm — весь CSS и JS inline в `index.html`. Любой внешний ресурс сломает офлайн-режим и его придётся руками вносить в `ASSETS` в `sw.js`.
2. **Инвариант данных:** для каждого `DATA[i]` — `answer === PARADIGMS[v][PERSON_ORDER.indexOf(person)]`.
   Каждый `v` либо в `EXCEPTIONS`, либо ровно в одной группе `CONJ_GROUPS[*].verbs`.
   После правки данных прогонять проверку целостности (см. §5).
3. **Новый глагол = 3 правки:** запись в `PARADIGMS`, членство в группе или в `EXCEPTIONS`, список в `<footer id="footerNote">`.
4. **Стиль UI:** только переменные из `:root`, серифная Georgia для контента / system-ui для интерфейса, скруглённые карточки. Мобильный — одна колонка (`@media max-width:600px`).
5. **Язык:** UI и грамматические объяснения по-русски, примеры по-польски. Предложения — бытовые, уровня A1.
6. **Иконки не редактировать вручную** — править `icons/icon.svg` и перегенерировать (см. §7).
7. После правок — `./deploy.sh "что изменил"`. Отдельных версий в именах файлов больше нет.

## 4. Текущее состояние контента

- **122 вопроса**, 29 глаголов → **12 тестов** максимум за сессию.
- Покрытие по лицам сильно неровное: `ja` 29, `ty` 29, `on/ona/ono` 26, `oni/one` 21, `my` 10, `wy` 7.
- Покрытие по глаголам: от 3 (`spać`, `gotować`, `pływać`…) до 6 (`być`, `mieć`).

### Известные шероховатости (не трогать без запроса)

- **Нумерация спряжений не польская.** В польской традиции: I = `-ę/-esz` (*pisać*), II = `-ę/-isz/-ysz` (*mówić*), III = `-am/-asz` (*czytać*), IV = `-em/-esz` (*jeść*, *wiedzieć*). В проекте A = «I», C = «II», D = «III» — то есть I и III местами. Переименование сломает привычку пользователя, поэтому только по явной просьбе.
- **`spać` в группе D** формально ок по окончаниям (śpię/śpisz), но чередование `a→ś` не объясняется. Кандидат в исключения или в отдельную подгруппу.
- Комментарий `// 9` рядом с `MAX_TESTS` устарел — фактически 12.
- Хвост из 2 вопросов (122 % 10) в сессию не попадает никогда.
- Ответы с диакритикой без поблажек — опечатка `mowie` засчитывается как ошибка.

## 5. Проверка целостности данных

Быстрая сверка ответов с парадигмами (запускать после правки `DATA`/`PARADIGMS`):

```bash
node -e "$(sed -n '/^const PERSON_LABEL/,/^];$/p' index.html); const idx=p=>PERSON_ORDER.indexOf(p); let bad=0; DATA.forEach((q,i)=>{const f=PARADIGMS[q.v]; if(!f){console.log('нет парадигмы:',q.v);bad++;return;} if(f[idx(q.person)]!==q.answer){console.log(i,q.v,q.person,'ожидалось',f[idx(q.person)],'а в DATA',q.answer);bad++;} const g=EXCEPTIONS.has(q.v)||Object.values(CONJ_GROUPS).some(G=>G.verbs.includes(q.v)); if(!g){console.log('глагол без группы:',q.v);bad++;}}); console.log(bad?bad+' проблем':'OK: '+DATA.length+' вопросов, '+Object.keys(PARADIGMS).length+' глаголов')"
```

## 6. Куда расширять

Обсуждаемые направления (ничего из этого ещё не начато):

- **Контент в текущем тренажёре:** добить `my`/`wy` до баланса, довести каждый глагол до 6 форм, добавить глаголы A1 (`wracać`, `dzwonić`, `oglądać`, `sprzątać`, `myć się`, `budzić się`, `nazywać się`, `wstawać`, `brać`, `dawać`).
- **Новые темы (каждая — свой HTML по тому же шаблону):** прошедшее время, падежи (Biernik / Narzędnik / Miejscownik), числительные и время, множественное число, предлоги, притяжательные, вид глагола.
- **Механика:** режим повторения только ошибок, сохранение прогресса в `localStorage`, мягкая проверка диакритики с предупреждением, выбор темы/глаголов перед стартом, обратный перевод RU→PL, озвучка через Web Speech API.
- **Структура:** если тренажёров станет много — общий `index.html` со списком модулей.

## 7. iPhone: установка и обновление

Приложение живёт на GitHub Pages и ставится на домашний экран как PWA.

**URL сайта:** `<заполнить после создания репозитория>`

### Разовая установка на телефон

1. Открыть URL в **Safari** (именно Safari — Chrome на iOS не умеет ставить на домашний экран).
2. Кнопка «Поделиться» → **«На экран «Домой»»** → «Добавить».
3. Появится иконка «Polski». Открывается на весь экран, без адресной строки, работает офлайн.

### Обновление

```bash
./deploy.sh "что изменил"
```

Коммитит, пушит, печатает URL. Через ~30 секунд GitHub Pages пересобирается.
На телефоне достаточно закрыть и снова открыть иконку **при наличии сети** —
service worker ходит в сеть первой очередью, поэтому свежая версия подтягивается сразу.
Офлайн отдаётся последняя удачно загруженная версия.

Если версия всё равно застряла: на айфоне «Настройки → Safari → Очистить историю и данные»
либо удалить иконку с домашнего экрана и поставить заново.

### Локальная проверка перед публикацией

Service worker требует `https://` или `localhost` — с `file://` он не зарегистрируется
(само приложение при этом откроется и будет работать, просто без офлайн-кэша).

```bash
python3 -m http.server 8765
```

и открыть `http://localhost:8765`. Чтобы проверить с самого айфона по домашнему Wi-Fi:
`http://<локальный-IP-мака>:8765` — но «На экран «Домой»» оттуда ставить не стоит,
иконка привяжется к адресу мака.

### Перегенерация иконок

Править `icons/icon.svg`, затем:

```bash
for s in 180 192 512; do sips -s format png -Z $s icons/icon.svg --out icons/icon-$s.png; done
sips -s format png -Z 512 icons/icon-maskable.svg --out icons/icon-maskable-512.png
```

`icon-maskable.svg` — та же «ę», но мельче: у maskable-иконок Android обрезает края,
содержимое должно помещаться в центральные 80%.
