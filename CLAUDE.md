# Polski Kurwa — тренажёр польского языка

Учебный проект: интерактивные тесты по польскому для самостоятельного изучения (A1 → выше).
Интерфейс и объяснения — **на русском**, материал — на польском.
Живёт на GitHub Pages, ставится на iPhone как приложение.

> Этот файл — рабочая память проекта. Читай его перед каждой задачей и **обновляй**,
> когда меняется структура, добавляется тема или принимается новое решение.

## 2. Архитектура

```
<head>                мета + PWA-теги + запрет зума
<style>               игровая тема: :root токены, панели, кнопки, свайпер, карточки
<body>                HUD (рекорд + очки), #app, модал
<script>
  ОБЩЕЕ               shuffle(), normalize()
  ТЕМА: ГЛАГОЛЫ       PERSON_*, PARADIGMS, EXCEPTIONS, CONJ_GROUPS, VERB_DATA
  ТЕМА: ЧИСЛИТЕЛЬНЫЕ  NUM_SUBTOPICS, NUM_REF, NUM_DATA
  РЕЕСТР ТЕМ          TOPICS, TOPIC_ORDER, SUB_EMOJI
  ОЧКИ                levenshtein(), similarity(), gradeAnswer()
  РЕКОРДЫ             loadBest()/saveBest() → localStorage
  ДВИЖОК              buildSwiper() → renderSetup / renderQuiz / renderSummary
```

### Четыре экрана

`topic` (свайп тем → «Выбрать») → `sub` (свайп подтем + число тестов → «Старт») → `quiz` → `summary`.
Переключает `state` + `render()`. У темы без подтем экран `sub` показывает только настройки.

### Свайпер

`buildSwiper(slides, activeIndex, onChange)` → `{html, init(root)}`, `init` возвращает `{settle, jump}`.
Лента на `overflow-x:auto` + `scroll-snap-type:x mandatory`, **во всю ширину экрана**:
у `.swiper` отрицательные поля, равные горизонтальному отступу `body`, слайд 84% + `padding: 0 8%`
у трека, чтобы крайние карточки центрировались. Соседняя карточка выглядывает и уезжает за край.
Стрелок нет — на компьютере переключают кликабельные точки.

Активный слайд ищется **по ближайшему к центру** (`nearest()`), а не делением на ширину:
работает при любых отступах и процентных ширинах.

Два места, где легко наступить на грабли:

- **`settle()` обязан проверять `track.isConnected`.** У открепленного от страницы элемента
  `scrollLeft` равен нулю, и отложенный пересчёт после перерисовки экрана «возвращал» свайпер
  на первый слайд, молча меняя тему уже в середине теста. Ровно этот баг здесь был.
- **Кнопка «Играть» вызывает `settle()` перед стартом.** Событие прокрутки приходит с задержкой,
  и без этого быстрый свайп + сразу тап запускал бы предыдущую тему.

### Очки

`gradeAnswer(q, value)` → `{sim, points, exact, verdict}`.

- Сходство — расстояние Левенштейна: `1 − distance / max(длина)`, берётся лучшее из `answer` и `alt`.
- `points = round(100 × sim)`. Точный ответ — 100, ни одной общей буквы — 0.
- `verdict`: `correct` (точно) · `close` (≥ 60%, показывается «Почти!») · `wrong`.
- Регистр и лишние пробелы не штрафуются (`normalize`). Диакритика штрафуется частично:
  `mowie` вместо `mówię` даёт 60%, а не ноль.
- Итог сессии: `stats.points / stats.maxPoints` → проценты → 1–3 звезды (40/70/90%).
- Рекорд в процентах хранится по теме в `localStorage['polski.best']`, всё в try/catch.

После проверки поле ввода **заменяется на `div.given`** — длинный ответ переносится
и виден целиком, чего input не умеет.

### Откуда берутся вопросы

Большая часть **генерируется на лету при загрузке**, а не лежит списком — иначе файл раздулся бы
до полумегабайта, а поддерживать 3000 строк вручную невозможно.

- `VERB_DATA = VERB_DATA_MANUAL.concat(buildVerbData())` — 122 написанных руками + 1518 собранных
  из `VERB_TAILS`: каждый глагол × 3 дополнения × 6 лиц, плюс вопрос «Czy …?» для всех лиц кроме `ja`
  («Czy ja…» звучит неестественно). Дополнения подобраны так, чтобы подходить ко всем лицам без изменений.
- `NUM_DATA = NUM_DATA_MANUAL.concat(buildNumData())` — 130 руками + 1231 по правилам.

Числительные считаются, а не перечисляются: `numToPl(n, род)`, `nounForm(n, [ед, им.мн, род.мн])`,
`yearLoc(год)`, таблицы часов. Три правила, на которых легко ошибиться:

- **Форма существительного зависит от числа:** 1 → ед.ч., 2–4 → им.мн. (*dwa lata*),
  остальное → род.мн. (*pięć lat*). Считает `nounForm`.
- **Род работает на «2», но не на «1» в составных:** *dwadzieścia dwie książki*, но
  *dwadzieścia jeden książek* — там `jeden` и родительный. Флаг `oneGender` в `under1000`.
- **В годе склоняется только последний элемент:** *tysiąc dziewięćset osiemdziesiątym piątym*.

Все шаблоны числительных — с переходным глаголом и винительным падежом, поэтому «1» с существительными
женского рода пропускается: винительный там *jedną książkę*, а не *jedna książka*.

### Рейтинг и прогресс

`localStorage['polski.progress.v1']` — записи по ключу `тема` и `тема:подтема`
(`recKey(topicId, subId)`, без подтемы → `тема:all`): `{points, best, played}`.
Уровень считается от `best`: 🌱 Новичок < 40 · 📗 Ученик < 60 · 💪 Уверенно < 80 · 🎓 Знаток < 95 · 👑 Мастер.
Показывается на карточках выбора (`pickCard`) и в итогах. Всё в try/catch.

### Контракт темы

Движок не знает про глаголы и числительные — только про общий формат вопроса:

```js
{
  g:        'ключ группы',      // статистика и разбор ошибок
  hint:     'подпись',          // пилюля в шапке карточки
  sentence: 'Ona ___ miła.',    // ровно один пропуск ___
  answer:   'jest',
  alt:      ['вариант'],        // необязательно
  ref:      'ключ справки'      // что открыть в модале
}
```

Сама тема в `TOPICS`:

```js
{
  id, title, subtitle,
  emoji: '🗣️',                   // в кружке на карточке выбора
  color: 'green' | 'amber',       // класс .pick-c-<color>
  level: 'A1',
  subtopics: [{id,label,caption}] | null,   // null = свайпера подтем нет
  note:     'строка под кнопкой Играть',
  blockInput: false,              // true = поле под предложением на всю ширину

  questions(subs),                // subs = Set выбранных подтем или null
  groupLabel(key),
  wrongHtml(q),                   // БЕЗ ведущей иконки — её ставит движок (✕ или ≈)
  adviceHtml(key),
  reference(refKey)               // → {title, tag, sub, cols, rows}
}
```

Подтемы выбираются **по одной** (свайпер), первым слайдом идёт «Всё подряд» (`id: null`) —
он и даёт смешанную тренировку.

### Как добавить тему

1. Блок данных в `<script>` рядом с остальными.
2. Объект в `TOPICS` по контракту выше.
3. `id` в `TOPIC_ORDER`.
4. Класс `.pick-c-<color>` в стилях, если нужен новый цвет.
5. Эмодзи подтем — в `SUB_EMOJI`.

## 3. Правила при изменениях

1. **Перед крупной правкой — `./backup.sh "что собираюсь делать"`.** Плюс git-метка на удачную версию: `git tag -f vN-описание`. Откат: `cp backups/index_ДАТА.html index.html`.
2. **Ноль зависимостей и ноль сборки.** Никаких CDN и npm. Любой внешний файл сломает офлайн и его придётся вносить в `ASSETS` в `sw.js`.
3. **Зум запрещён намеренно** — `user-scalable=no` в `<meta viewport>`, `touch-action:manipulation` в CSS (двойной тап) и `preventDefault` на `gesture*` (щипок в Safari). Не «чинить» это как баг.
4. **Инвариант глаголов:** `answer === PARADIGMS[v][PERSON_ORDER.indexOf(person)]`; каждый глагол либо в `EXCEPTIONS`, либо ровно в одной группе `CONJ_GROUPS`.
5. **Инвариант числительных:** `sub` есть в `NUM_SUBTOPICS`, для него есть таблица в `NUM_REF`, в предложении ровно один `___`.
6. После правки данных — прогнать проверку целостности (§5).
7. **Подтема должна тянуть на полный тест** — минимум 10 вопросов, иначе её нельзя выбрать одну.
8. **Стиль UI — игровой:** только токены из `:root`, шрифт `ui-rounded`, объёмные кнопки (`.gbtn` с `box-shadow: 0 5px 0 <тёмный>`, при нажатии уезжают вниз), панели с рамкой и внутренним бликом, эмодзи вместо иконок. Мобильный — одна колонка (`max-width:620px`).
9. **Ширина поля ввода не зависит от длины ответа** — иначе она его подсказывает.
10. **Язык:** UI и объяснения по-русски, примеры по-польски, уровень A1.
11. **Иконки не редактировать вручную** — править `icons/icon.svg` и перегенерировать (§7).
12. После правок — `./deploy.sh "что изменил"`.

### Отдельно про содержание числительных

Числительные в польском управляют падежом существительного, поэтому **пропуск всегда только на само числительное**, а существительное уже стоит в предложении в правильной форме. При добавлении вопросов сверяй:

- 1 → единственное число: *jeden złoty*
- 2, 3, 4 и составные на них → именительный мн.: *dwadzieścia dwa **lata**, sześćdziesiąt cztery **osoby***
- 5–21 и всё остальное → родительный мн.: *dwadzieścia pięć **lat**, sto jeden **złotych***
- после 2/3/4 тысяч — *tysiące*, после 5+ — *tysięcy*

| **Всего** | **3001** | | 252 | |

**Глаголы.** Группы: A «I спряжение» (-ać, *czytać*), B «на -ować», C «II спряжение» (-ę/-esz, *pisać*),
D «III спряжение» (-ę/-isz, *mówić*), E «тип на -mieć» (*rozumieć*), плюс `EXCEPTIONS`:
być, mieć, iść, jechać, jeść, chcieć, móc, wiedzieć, brać.

**Числительные.** Цифры 108 · Десятки 206 · Сотни 220 · Тысячи 253 · Даты 275 · Время 299.

### Известные шероховатости (не трогать без запроса)

- **Нумерация спряжений не польская.** В польской традиции I = `-ę/-esz` (*pisać*), II = `-ę/-isz` (*mówić*), III = `-am/-asz` (*czytać*). В проекте I и III местами. Переименование сломает привычку — только по явной просьбе.
- **`spać` в группе D** формально ок по окончаниям (śpię/śpisz), но чередование `a→ś` не объясняется.
- Сгенерированные предложения однотипны по структуре («{Местоимение} ___ {дополнение}» и «Czy …?») — берут разнообразием словаря, а не синтаксиса. Руками написанные 252 предложения живее.
- Хвост вопросов после деления на десятки в сессию не попадает (остаток от деления на 10).
- Диакритика сверяется строго: `mowie` ≠ `mówię`. Регистр и лишние пробелы прощаются.

## 5. Проверка целостности данных

Прогонять после любой правки данных или генераторов. Сверяет ответы с парадигмами,
членство глаголов в группах, единственный пропуск в предложении и наполненность подтем.

## 6. Куда расширять

- **Числительные:** порядковые (pierwszy/drugi…), «ile masz lat», цены с гроszami, номера телефонов, собирательные (dwoje, troje).
- **Глаголы:** добить `my`/`wy`, довести каждый глагол до 6 форм, добавить A1-глаголы (`wracać`, `dzwonić`, `oglądać`, `sprzątać`, `myć się`, `budzić się`, `nazywać się`, `wstawać`, `brać`, `dawać`).
- **Новые темы (каждая — объект в `TOPICS`):** прошедшее время, падежи (Biernik / Narzędnik / Miejscownik), множественное число, предлоги, притяжательные, вид глагола.
- **Механика:** режим повторения только ошибок, прогресс в `localStorage`, мягкая проверка диакритики с предупреждением, обратный перевод RU→PL, озвучка через Web Speech API.

### Перегенерация иконок

```bash
for s in 180 192 512; do sips -s format png -Z $s icons/icon.svg --out icons/icon-$s.png; done
```
