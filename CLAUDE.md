# Polski Kurwa — тренажёр польского языка

Учебный проект: интерактивные тесты по польскому для самостоятельного изучения (A1 → выше).
Интерфейс и объяснения — **на русском**, материал — на польском.

> когда меняется структура, добавляется модуль или принимается новое решение.

## 2. Архитектура одного файла

Порядок внутри HTML (строки указаны для v6_2, они сдвигаются при правках):

```
:root { --переменные-цветов }      ~8      палитра (бумажно-бежевая тема)
<style>                            7–360   все стили
<body> header / #app / footer      362–377 «скелет»: весь UI рисуется в #app из JS
.modal-backdrop / #modalBox        374–376 общий модал (таблица спряжения + подтверждения)
<script>                           379+
  PERSON_LABEL / PERSON_ORDER      380–388 6 лиц
  PARADIGMS                        390–420 29 глаголов × 6 форм
  EXCEPTIONS                       422     Set неправильных глаголов
  CONJ_GROUPS                      424–465 группы спряжения A–E
  DATA                             475–626 122 вопроса
  движок                           628+    shuffle → batches → 3 экрана
```

### Модель данных

```js
PARADIGMS["mówić"] = ["mówię","mówisz","mówi","mówimy","mówicie","mówią"]
// строго в порядке PERSON_ORDER: ja, ty, on/ona/ono, my, wy, oni/one

CONJ_GROUPS.A = {
  label:      "I спряжение (тип czytać, -am/-asz)",  // полное, в фидбэке ошибки
  shortLabel: "I спряжение",                          // короткое, в модале и итогах
  infEnding:  "-ać",                                  // окончание инфинитива
  baseVerb:   "czytać",                               // образец группы
  verbs:      [...],                                  // членство определяется ЗДЕСЬ
  endings:    { ja:"-am", ty:"-asz", ... }            // ключи = PERSON_ORDER
}

DATA[i] = {
  v:        "mówić",              // ключ в PARADIGMS (обязателен!)
  person:   "on/ona/ono",         // одно из PERSON_ORDER
  sentence: "Ona ___ po niemiecku.", // ровно один плейсхолдер ___
  answer:   "mówi"                // = PARADIGMS[v][индекс person]
}
```

### Группы спряжения (текущая раскладка)

| Ключ | Ярлык | Инфинитив | Образец | Глаголы |
|---|---|---|---|---|
| A | I спряжение | -ać | czytać | czytać, mieszkać, słuchać, znać, grać, pomagać, pływać |
| B | на -ować | -ować | pracować | pracować, kupować, gotować |
| C | II спряжение | -ać / -ić | pisać | pisać, pić |
| D | III спряжение | -ić / -yć | mówić | mówić, robić, lubić, widzieć, tańczyć, uczyć się, jeździć, spać |
| E | тип на -mieć | -mieć | rozumieć | rozumieć |
| — | Исключения (`EXCEPTIONS`) | — | być | być, mieć, iść, jechać, jeść, chcieć, móc, wiedzieć |

### Движок

- `BATCH_SIZE = 10`, `MAX_TESTS = Math.floor(DATA.length / BATCH_SIZE)` — растёт сам при добавлении вопросов.
- `buildBatches()` — один `shuffle` всего `DATA`, режется на десятки. **Внутри сессии вопросы не повторяются.**
- Три экрана через `state` + `render()`: `start` (степпер + чипы 1/3/5/Все) → `quiz` → `summary`.
- `normalize()` = trim + lowercase + схлопывание пробелов. **Диакритика сравнивается строго**: `mowie` ≠ `mówię`.
- Проверка: `checkAnswers()` красит карточку, пишет фидбэк, копит `stats` (по группам + исключения).
- Фидбэк ошибки содержит кликабельную ссылку `.conj-link[data-verb]` → модал с полной таблицей форм.
- Итоги: SVG-радиал с анимацией, столбики ошибок по группам, до 2 советов «что подтянуть».
- Enter в поле = переход к следующему; в последнем = «Проверить». Пустые поля → модал-подтверждение.

## 3. Правила при изменениях

1. **Один файл, ноль зависимостей.** Никаких CDN, npm, сборки. Всё inline. Файл должен работать офлайн с `file://`.
2. **Инвариант данных:** для каждого `DATA[i]` — `answer === PARADIGMS[v][PERSON_ORDER.indexOf(person)]`.
   Каждый `v` либо в `EXCEPTIONS`, либо ровно в одной группе `CONJ_GROUPS[*].verbs`.
   После правки данных прогонять проверку целостности (см. §5).
3. **Новый глагол = 3 правки:** запись в `PARADIGMS`, членство в группе или в `EXCEPTIONS`, список в `<footer id="footerNote">`.
4. **Стиль UI:** только переменные из `:root`, серифная Georgia для контента / system-ui для интерфейса, скруглённые карточки. Мобильный — одна колонка (`@media max-width:600px`).
5. **Язык:** UI и грамматические объяснения по-русски, примеры по-польски. Предложения — бытовые, уровня A1.
6. Версию поднимать в имени файла при заметном изменении функциональности.

## 4. Текущее состояние контента

- **122 вопроса**, 29 глаголов → **12 тестов** максимум за сессию.
- Покрытие по лицам сильно неровное: `ja` 29, `ty` 29, `on/ona/ono` 26, `oni/one` 21, `my` 10, `wy` 7.
- Покрытие по глаголам: от 3 (`spać`, `gotować`, `pływać`…) до 6 (`być`, `mieć`).

### Известные шероховатости (не трогать без запроса)

- **Нумерация спряжений не польская.** В польской традиции: I = `-ę/-esz` (*pisać*), II = `-ę/-isz/-ysz` (*mówić*), III = `-am/-asz` (*czytać*), IV = `-em/-esz` (*jeść*, *wiedzieć*). В проекте A = «I», C = «II», D = «III» — то есть I и III местами. Переименование сломает привычку пользователя, поэтому только по явной просьбе.
- **`spać` в группе D** формально ок по окончаниям (śpię/śpisz), но чередование `a→ś` не объясняется. Кандидат в исключения или в отдельную подгруппу.
- Комментарий `// 9` рядом с `MAX_TESTS` устарел — фактически 12.
- Хвост из 2 вопросов (122 % 10) в сессию не попадает никогда.
- Ответы с диакритикой без поблажек — опечатка `mowie` засчитывается как ошибка.

## 5. Проверка целостности данных

Быстрая сверка ответов с парадигмами (запускать после правки `DATA`/`PARADIGMS`):

```bash
node -e "$(sed -n '/^const PERSON_LABEL/,/^];$/p' polski_a1_czasowniki_v6_2.html); const idx=p=>PERSON_ORDER.indexOf(p); let bad=0; DATA.forEach((q,i)=>{const f=PARADIGMS[q.v]; if(!f){console.log('нет парадигмы:',q.v);bad++;return;} if(f[idx(q.person)]!==q.answer){console.log(i,q.v,q.person,'ожидалось',f[idx(q.person)],'а в DATA',q.answer);bad++;} const g=EXCEPTIONS.has(q.v)||Object.values(CONJ_GROUPS).some(G=>G.verbs.includes(q.v)); if(!g){console.log('глагол без группы:',q.v);bad++;}}); console.log(bad?bad+' проблем':'OK: '+DATA.length+' вопросов, '+Object.keys(PARADIGMS).length+' глаголов')"
```
